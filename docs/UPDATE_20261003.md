membership checks and returns a verified existing receipt before opening a
no-op stage. It also binds historical snapshot envelopes/source/summary,

## Round 3: delivery and scale

The producer now opens stages lazily and reuses the just-published batch when a
pause falls exactly on its boundary. The prior frozen probe is rerun without
changing its expectation. Added a portable binary consumer/SDK example and the
create-only [`verify_local_workflow.py`](../probes/verify_local_workflow.py)
entry point for actual installed console, separate consumer and allocation/scale
checks. The working-tree suite passed 65 tests; final ordinary-wheel evidence
and measurements are recorded below after execution. No version increment or
test-count increase is represented as a defect repair.

The baseline ordinary wheel also reran all five frozen external probe scripts:
the signed-zero public reproduction, four domain-rejection categories, original
six-group list oracle (40 streams/3,200 records/160 resumes), six numeric groups
(55 enum cases and 241 binary multiset realizations), and five final zero groups
(24 typed-zero cases, 9 nonzero representations, eight-key SDK/console all cuts,
6,562 actual hash calls including the envelope for 6,561 candidates). All passed.
New-version rerun results remain separately attributable in the new update
namespace; older external probe files/results are not rewritten.

## Scope and handoff

See [the complete local protocol](LOCAL_COMMITS.md) for one-writer, disk-retention,
source trust, O(history) validation/O(generations) reader metadata, bounded record
writing, hardware-durability and external consumer transaction limits. Source
verification/build times and document generation time are separate receipt
fields when recorded; older commands without such timestamps are not assigned
invented query times. There was no implementation harness misattribution in
these three reproductions. The build harness uses available `pip wheel`, not an
assumption that a global `build` module is installed. Publication, fresh remote
CI and new independent review remain separate work; no self-score is assigned.
