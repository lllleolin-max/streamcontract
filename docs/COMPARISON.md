# Measured mechanism and bounded use case

Primary sources verified 2026-10-03:

- [Soda Contract Language reference](https://docs.soda.io/reference/contract-language-reference) documents schema, validity, row-count, aggregate thresholds, custom metrics and grouping checks. Those checks already exist; StreamContract does not claim to invent data contracts or aggregate quality tests. Its contract syntax and local JSONL workflow are separate.
- [Apache Flink stable windows documentation](https://nightlies.apache.org/flink/flink-docs-stable/docs/dev/datastream/operators/windows/) (v2.3.0 when read) documents event/processing-time windows, allowed lateness and late side outputs. [Flink checkpointing](https://nightlies.apache.org/flink/flink-docs-stable/docs/dev/datastream/fault-tolerance/checkpointing/) documents restoring operator state and replaying source records. StreamContract credits these established mechanisms and provides a much narrower local implementation.

The useful distinction is an inspectable installable local gate combining exact aggregate state, explicit late/resource dispositions, raw-payload-free evidence, source-prefix-bound resume and a single JSON decision protocol. These components interact: a resume must preserve the watermark or delayed events would change window membership; preserved moments must retain precision or a resumed threshold could differ; invalid events must not advance the watermark; privacy means downstream quarantine retrieves payloads by source sequence instead of storing them here. There is no claim of world-first novelty or of a capability absent from all incumbent configurations.

`python benchmarks/compare.py` actually executes seven disclosed synthetic cases. Row/domain baseline calls the same field validator. Processing-time baseline uses the same aggregate checks/grouping but one-millisecond synthetic arrival times rather than source timestamps. The aggregate ablation removes the reference-mean check while retaining count checks. The disorder-budget ablation sets delay and lateness to zero. Resume is checked at the middle of every case. The high-cardinality case offers 10,000 distinct groups, stops before record 17 and retains 16 groups. Measured allocation/time is local Python-only telemetry; it is not a process RSS guarantee or throughput comparison.

The main fixture separates high-latency events into their own source-time window even though arrivals interleave. The useful question is whether release/quarantine changes, not whether this code is faster than Soda/Flink. Clean disorder demonstrates equal clean decisions. Insufficient samples and too-small time budgets demonstrate unfavorable cases: window isolation can introduce investigate actions, and poor delay policy quarantines otherwise valid old data. No incumbent binaries or customer workloads were run, so no performance/superiority claims follow.

Buyer hypothesis: a platform/data engineering team rehearsing a JSONL export or gating a modest append-only producer feed before a warehouse load, when maintaining a cluster or exposing raw debugging rows is disproportionate. The action protocol can block a release or route a known sequence to an upstream quarantine store. Integration requires an ordered lane and a downstream idempotent sink; expected-volume completeness, outlier distributions, large cardinality and broker coordination require other tools.

Bounded economics, **not validated demand**: if an engineer currently spends 30 minutes rebuilding an ad hoc per-window summary after each failed import and can reproduce it with a 5-minute command/configuration cycle, the hypothetical saving is 25 minutes per incident. Ten incidents/month would save about 4.2 engineer-hours/month, before installation, contract calibration and review costs. The benchmark establishes a missed-decision mechanism, not that these frequencies/times occur in a business. No actual users, revenue or willingness to pay is known. The narrow maintainable scope is JSONL/flat scalar schemas/tumbling windows/fixed thresholds, under explicit resource limits.
